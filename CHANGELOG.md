# Changelog

All notable changes to EmoLens are documented here.

## [0.1.0] - 2026-08-16

### Added
- Interactive 3D body mapping with 12 clickable zones
- LangGraph-powered AI emotion mapping pipeline (Gemini 3.6 Flash + Groq Llama 3.3 70B fallback)
- Body sensation check-in flow with intensity scaling
- Personal emotion dictionary with local-first learning engine
- Shareable Communication Cards
- Evidence-based coping suggestion engine
- Crisis detection with routing to 988 Suicide & Crisis Lifeline
- Local-first persistence (IndexedDB) with optional Supabase cloud sync
- Google OAuth via Supabase Auth
- Accessibility panel with reduced-motion support
